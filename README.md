# 慈恩镇档案管理办公室

一个 ARG（替代现实游戏）悬疑解谜项目：**伪装成政府档案机构官网，实际是藏在网页里的真相拼图。**

玩家以为自己在浏览一个普通档案馆网站，直到发现数据异常、失踪者的名字出现在培训名单里、一扇需要密码的门……最终意识到：**这整座档案馆，藏着一个 17 年前的秘密。**

**纯 HTML/CSS/JS 单文件 · 无后端 · 部署即玩**

---

## 🚀 快速开始

### 本地体验

```bash
cd arg-game
npm start              # node serve.js → http://localhost:8081（手机同一 WiFi 访问局域网 IP）
```

**推荐入口**：`http://localhost:8081/desktop.html` —— 档案馆内网终端（2009 年停摆的电脑），浏览器程序里打开官网。

> 建议用服务器方式体验完整功能（localStorage 进度存储最稳定；双击 html 文件在部分浏览器有跨文件限制）。

### 双入口结构

```
desktop.html  ← 终端入口（开机画面 → 桌面，系统时间停在 2009-03-17）
  └─ 🌐 内网浏览器 → 打开官网（index.html，零改动）
        ├─ 官网解密链：linyuan → CE-2009-005 → xf001 + 2009
        └─ 管理员解锁 → 桌面检测到（l2Unlocked / cz_admin_ok 双通道）
              └─ 内部档案 / 信息 / 工具 解锁（终端时间同步到 2026）
index.html   ← 官网入口（直接访问像普通网站，ARG 伪装层）
              └─ 「加入我们」裂缝入口：加载 3 秒后从导航栏右侧突然滑入（全站唯一黑块），点击直达终端；进过终端后自动消失（cz_evt_joined）
```

### 部署上线

**首选：腾讯云 EdgeOne Pages**（大陆可访问 · 免费 · 免实名 · push 自动部署）—— 详见 [docs/线上部署-EdgeOne.md](docs/线上部署-EdgeOne.md)

**备选：GitHub Pages**（免费，3 分钟）
1. 在 GitHub 新建仓库，把仓库内容 push 上去
2. 仓库 Settings → Pages → Source 选 `main` 分支 → Save
3. 等待 1 分钟 → 访问 `https://<你的用户名>.github.io/<仓库名>/`

> ⚠️ 分发通道**只用 EdgeOne 或 GitHub Pages**（HTML 正确渲染）。
> 勿用 jsDelivr（cdn.jsdelivr.net/gh/…）：2026 年起其对 .html 一律返回 `text/plain`，浏览器只显示源码不渲染。

**部署后验证（3 步，1 分钟）**：
1. 访问线上根路径 → 官网正常渲染（无源码裸文本）
2. 访问 `/assets/img/enci-festival.svg` → 图片正常显示（svg MIME 正确）
3. 访问 `/test/test-tracking.js` → 返回 404 或源码（剧透防护：测试脚本随仓库在线上，但路径不对外公开；介意可删 `test/` 目录后重新 push）

## 🛠 技术说明

- **单文件**：`index.html`（官网，约 1400 行）+ `desktop.html`（桌面终端，约 1700 行），各自包含全部结构/样式/逻辑
- **无后端**：纯静态，可部署到任意静态托管
- **音频**：Web Audio API 合成——"会说话的吉他"旋律（talk box 共振峰扫描 + 踏板钢吉他滑音 + 延迟回声），无任何音频文件
- **存储键**（localStorage，同源共享；cz_* 惯例）：
  - 进度类：`cz_stage_log`（游玩轨迹 JSON 数组）、`cz_dict_prog`（实时追逐进度）
  - 事件类：`cz_admin_ok`、`cz_evt_gate3_ok/open`、`cz_evt_handover_done`、`cz_evt_wang_read`、`cz_evt_morse_break`、`cz_evt_search_tingdian`、`cz_evt_final_read`、`cz_evt_choice_shouzheng/self/refuse`、`cz_evt_good_end`、`cz_evt_joined`（「加入我们」入口：进过终端即消失）
  - 验证式/彩蛋：`cz_evt_judge_0147`（01:47 出入者判断）、`cz_evt_judge_redbook`（红本交接判断）、`cz_evt_bp_erase`（批注擦除还原）
  - R1-R5 深度内容：`cz_evt_roster_decode`（盘点单解码）、`cz_archive_code`（12 位归档码，12/12 生成）、`cz_evt_006_unlocked`（卷宗六解锁）、`cz_evt_timeline`（时间线归档）、`cz_visitor_id`（唯一访客编号 05-XXXX）、`cz_evt_shadow_members`（影子网络成员）、`cz_evt_shadow_join`/`cz_evt_question`（暗网入口）、`cz_share_copy`/`cz_share_foreign`（传播回收计数）、`cz_invasion_terminal`/`cz_invasion_site`（视觉高光幂等）、`cz_you_here`（滚动回应）、`cz_recap_shown`（会话级交接摘要，sessionStorage）
  - 状态类：`cz_resist`（0-3 反抗点）+ `cz_resist_d1/d2/d3`、`cz_erase_cnt`（死亡次数）
  - 其他：`cz_audio_on`（背景音开关）、`cz_evt_seen`（消息去重）、`sessionStorage.cz_admin_unlock`（乱码条目顺序锁）
