# 慈恩镇档案管理办公室

一个 ARG（替代现实游戏）悬疑解谜项目：**伪装成政府档案机构官网，实际是藏在网页里的真相拼图。**

玩家以为自己在浏览一个普通档案馆网站，直到发现数据异常、失踪者的名字出现在培训名单里、一扇需要密码的门……最终意识到：**这整座档案馆，藏着一个 17 年前的秘密。**

**纯 HTML/CSS/JS 单文件 · 无后端 · 部署即玩**

---

## 🚀 快速开始

### 本地体验

```bash
cd arg-game
node serve.js          # → http://localhost:8081（手机同一 WiFi 访问局域网 IP）
```

**推荐入口**：`http://localhost:8081/desktop.html` —— 档案馆内网终端（2009 年停摆的电脑），浏览器程序里打开官网。

> 建议用服务器方式体验完整功能（localStorage 进度存储最稳定；双击 html 文件在部分浏览器有跨文件限制）。

### 双入口结构

```
desktop.html  ← 终端入口（开机画面 → 桌面，系统时间停在 2009-03-17）
  └─ 🌐 内网浏览器 → 打开官网（index.html，零改动）
        ├─ 官网解密链：linyuan → CE-2009-005 → xf001 + 2009
        └─ 管理员解锁 → 桌面检测到（l2Unlocked / cz_admin_ok 双通道）
              └─ 内部档案 / 信息 / 工具 解锁（终端时间同步到 2026）
index.html   ← 官网入口（直接访问像普通网站，ARG 伪装层）
```

### 部署上线

**GitHub Pages**（免费，3 分钟）
1. 在 GitHub 新建仓库（如 `arg-cizhen`），把仓库内容 push 上去
2. 仓库 Settings → Pages → Source 选 `main` 分支 → Save
3. 等待 1 分钟 → 访问 `https://<你的用户名>.github.io/arg-cizhen/`

**Vercel**（备选）
1. vercel.com 用 GitHub 登录 → New Project → 导入仓库
2. 默认设置直接 Deploy（纯静态站，零配置）

| | |
|---|---|
| 伪装层 | 慈恩镇档案管理办公室官网（政府风格：深红主色、新闻动态、档案查询、机构概况） |
| 终端层 | 内网终端桌面（desktop.html）：系统时间停在 2009-03-17，浏览器/档案/信息/工具四个程序 |

| 任务开场 | 开机 → 叮咚 → 「档案科·值班员」发来任务：整理今日补录档案 → 官网解密链完成后值班员回执存档（任务闭环） |

| L3 深渊区 | 07 号档案门禁（1942）→ 教会地下档案室备案记录：王执事与陈某对话录音抄本（「密码是你父亲设的」「红色笔记本」）→ 陈守正伏笔 |
| 交接班出口 | 工具程序「交接班」tab 生成值班交接记录（任务进度汇总 + 官网/终端链接 + 一键复制）——玩家向朋友转发的 ARG 传播载体 |
| 访问统计伪装 | 官网页脚「今日访问量/总访问量」实时计数（localStorage），桌面系统消息动态显示「今日访问记录：N 次」——被监视感 + 数据伪装一体 |
| 游戏层 | 三段式解密链：密码门 → 卷宗 → 管理员权限完整卷宗 → 终端程序解锁 |
| 核心体验 | "失踪 17 年的人，出现在今年的培训班名单里"——细思极恐 |
| 玩法时长 | 约 15-40 分钟（取决于探索深度） |

## 🛠 技术说明

- **单文件**：`index.html`（约 1000 行）包含全部结构/样式/逻辑
- **无后端**：纯静态，可部署到任意静态托管
- **音频**：Web Audio API 合成——"会说话的吉他"旋律（talk box 共振峰扫描 + 踏板钢吉他滑音 + 延迟回声），无任何音频文件
- **存储键**：
  - `localStorage.cz_audio_on` — 背景音开关
  - `sessionStorage.cz_admin_unlock` — 乱码条目顺序锁
