## 一、根基：河神不是传说，是现实

慈恩镇临河而居，镇名「慈恩」即河神恩泽。古代百姓每年向河神上贡，河神降雨保丰收，人神和谐，河神常以人形行走人间。

**河神以「香火气」为食。** 人肉、水果、祭品，本质上都只是香火气的一种载体。河神「吃」的不是实物，是供奉者的意念与气息。他无法拒绝贡品，正如人无法拒绝呼吸——那是神的本能，不是贪欲。

## 二、原罪：那场大旱

某年，天降大旱，方圆数千里无水。河神也无能为力。

百姓误以为河神发怒，走投无路之下，把河神在人间的挚友——一个叫**小禾**的小女孩——杀了、煮了，献给河神。**是她的父母亲手杀的。**（玩家侧：小禾的名字不出现——「镇上没人记得她叫什么了」。她名字所在的那一页，是名册里被撕掉的旧页之一（见第五节），她的存在与名字一起被抹除——这是世界观第一课。）

河神闻到了「很香的味道」，毫不怀疑地享用了。他只觉得这香味熟悉而温暖，却不知那是什么。

两三个月后，水恢复了。河神许久不见小禾，去问村民。村民告诉了他真相。

## 三、发疯与诅咒

河神发疯了。他给全镇人下了一个诅咒：**一年之后，所有人都会死去。**

诅咒的机制与「熟悉的味道」紧紧绑在一起——

> 河神每次闻到献祭孩童的味道，都会误以为「小禾回来了」，于是短暂恢复理智、诅咒解除。
> 可理智一回来，他环顾四周，看见的只有一具被煮的孩子尸体——于是明白「村民又杀了一个孩子来骗我」。
> 于是，他更疯，诅咒再起。

这是一个**双向陷阱**：村民靠骗河神续命，河神每次都被骗到更疯。谁都不是赢家。

## 四、女道士：幕后黑手与她的结局（已拍板）

一位**女道士**来到镇上，传播她的宗教，把慈恩镇当作自己的道场，**借河神修炼**。

她给村民出了那个「卡 bug」的办法：每年献祭一个孩童，用「熟悉的味道」安抚河神，换取诅咒暂缓。

但她不是救星。她的本质是：

> **她是让这场病慢点发作、好让她一直吸血的寄生虫。**
> 没有她，河神早已彻底失控、村民早已死绝、悲剧早已结束。
> 但她用「卡 bug」让献祭循环无限延续——用村民的命，喂一个疯神，来给自己续修为。

**她的结局（拍板：与河神融合，半人半神半疯）：**

她借河神修炼，修到最后，自己的灵魂和河神纠缠在了一起——她没能成仙，反而被河神反噬，成了河神「疯狂」的一部分。

- 她不再是「幕后黑手」，而是「**囚徒**」——被困在河底，既不是活着的人，也不是死掉的鬼
- 她维持献祭循环，不是因为野心，是因为**她自己也要靠香火气续命**，否则她会彻底消散
- 「河神吞噬一切血肉」的疯狂里，有她的执念——**河神的愤怒 + 女道士的欲望，纠缠成了一个彻底失控的存在**
- **献祭停不下来的真正原因**：不是村民怕死，而是河底那个融合体需要不断进食。它越饿越疯

**名册，就是她的「修炼供养名单」。** 她发明登记册来管理「每年献祭谁」——登记 = 选为祭品，抹除 = 完成献祭。看守者传承，是她的**道统**，徒弟传徒弟。

## 五、名册：祭品账本（实体化）

- **形态**：红皮封面旧笔记本，1942 年起启用为「组织化账本」，此前为道士私人记录（见留白）。
- **第一页**（陈父 1942 年笔迹，全游戏核心语句）：**「凡登记在册者，皆已不在人世。」**
- **第一页之前**：有被撕掉的页——**1972 年陈父反抗时撕下的更早记录**（制度源头，含小禾的名字——镇上没人记得她叫什么了）。他撕掉了旧记录的一部分，但没能毁掉名册主体（见第九节陈父弧线）。
- **性质**：名册不是失踪名单，是**祭品账本**。每登记一人，他的官方记录就被清除——户籍登记年份被改（1972 陈父）、寻人启事报头被撕（1972 走失者）、档案编号断档（2009-005 已归档不在公开列表）。他名字唯一存续的地方，就是名册。
- **红本抄本** = 名册的**数字化残页**（含第 23 页之后的「未编号抄本」）。玩家在终端里恢复出来的「红本抄本」——玩家以为是帮人查案，**实际拿到的是自己的处刑名单**。
- **红色笔记本（陈守正手里的秘密）** = 名册原件。老陈 2010 调离前留给他：「有一天会有人来找它的。他来了，你就把笔记本给他。」——老陈预判了玩家（林远的继承者）会出现。

## 六、献祭机制的恶化（从孩童到一切血肉）

1. **起始**：每年献祭一个孩童。
2. **扩张**：孩童不够用了，村民开始「抢别家孩子、诱导外人搬进来」——外来者以为搬进慈恩镇是福气，实则是进了屠宰场。
3. **全年龄段的转折**：某年，河神疯到引发洪水。四五个年轻人下河救灾，有人被洪水卷走（被河神吞了），剩下的人突然发现——**自己身上的诅咒消失了**。他们这才明白：河神已疯到「不挑食」，**成年人的血肉也能当祭品**。
4. **终局倒计时**：河神越发疯狂、没有理智，开始**吞噬一切血肉**。献祭的门槛越抬越高，镇子快撑不住了。

## 七、为什么在地下室：1942 组织化节点

1942 年抗战，教会地下室表面是「战时避难所」，实际是**祭品账房**——名册属于「不能销毁、也不能见光」的一类：

- **不能销毁**：名册是「清算之日」的账本，也是道士道统的凭证；
- **不能见光**：看到名册 = 知道献祭存在 = 自己也必须被登记。

它锁在地下室东墙的**隐藏夹层**里（图纸已有：「地下室东墙有夹层，备案图纸上没有」）。1942 年「有人从地下室搬出一口锁箱」= 上一任看守者把名册连同锁箱**指定传承**给陈父（当年 20 岁的学徒）。锁箱 = 名册的容器。

**锁箱流转链**：**上一任看守者 → 陈父 →（1972）王执事 →（2009）老陈 → 陈守正 →（2026）玩家**。

## 八、高层渗透：弄祭品的网络

高层早就有很多慈恩镇的人了。一定次数的献祭，就是在这种背景下重重掩护展开的。

慈恩镇是**总部**，往外渗透的人不是去玩权力游戏，是去**弄祭品**。这解释了为什么户籍能改、寻人启事能撕、案件能压——因为权力体系里，到处都是自己人。

**年表**：

- 大旱 → 小禾被献祭 → 水复 → 河神知真相 → 诅咒 → 女道士来卡 bug → 献祭循环开始（年代久远，不向玩家展开具体年份）
- **1942**：抗战，教会地下室成账房；名册组织化启用；锁箱指定传承给 20 岁陈父；陈父设门禁密码 1942（房子那年起的）
- **某年洪水**：年轻人下河救灾，发现成人血肉可当祭品（全年龄段转折）
- **1972.6**：陈父（约 50 岁）在交接日前动手——从库房取走名册、撕下第一页之前的旧记录（制度源头，含小禾名字），带册出逃想终结循环；失败被抹除，官方说法「走失」；库房盘点「少了一件东西，不见即补」；同月走失者寻人启事贴到教会门口，报头烂、名字看不清；户籍登记年份被改；名册交到王执事手中
- **2009.3.14-16**：老陈来访（门禁密码来历 / 1972 剪报 / 1942 锁箱）；王执事「老陈说17号停电，系统会停半天。正好。」→「明天的事，你我都别露面。」
- **2009.3.17**：停电掩护下名册转移；03:01 系统被断（执行者的动作）；值班者林远目击 → 当天失踪；王执事死于非正常（67 岁）
- **2010**：老陈「调离」（已注销），名册留陈守正：「有一天会有人来找它的。他来了，你就把笔记本给他。」
- **2026**：玩家（访客 05）被带到终端前

**看守者宿命（关键残酷设定）**：**交出名册之日，就是名字上名册之日。** 陈父（1972 交王执事→当天失踪）、王执事（2009 交老陈→死）、老陈（2010 交陈守正→注销）、林远（3-17 交接中断→被登记）——每一任看守最终都成为祭品。玩家 2026 接手名册 → 宿命轮到玩家。

**陈父弧线（觉醒者，反抗线核心）**：

| 阶段 | 时间 | 状态 |
|---|---|---|
| 被洗脑 | 1942（20 岁） | 被上一任看守者（女道士道统）指定接班，年轻单纯，以为「看守名册」是守护镇子的神圣职责 |
| 觉醒 | 1942-1972（30 年） | 亲手执行了三十年献祭，亲眼看着一个个孩子被登记、被抹除，渐渐看透——道士的道统从不保护看守者，看守者自己也只是祭品的备选 |
| 反抗失败 | 1972（约 50 岁） | 交接日临近（名字将被登记），决定动手：从库房取走名册，撕下「第一页之前」的旧记录（制度源头，含小禾），想带着名册出逃、毁掉循环。失败，被抹除，官方说法是「走失」 |

- **关键点**：他 1972 年「取走名册」不是偷窃求生，是带着名册出逃、想毁掉循环。他不是怕自己被献祭，是**不想再当帮凶**。
- **反抗线的价值**：陈父是第一个试图反抗的人，他失败了。玩家（访客 05）继承了这个身份，也就继承了这条**未完成的反抗**——玩家最后要不要重走陈父的老路？（本阶段无第三条路；「要不要重走」是下一阶段钥匙孔，见第十节钩子）

### C. 二选一（你以为在破案）

最终卷末尾出现**最终确认界面**，伪装成「指认真凶 / 确认移交对象」：

- **选项一：陈守正**（现任主任）
- **选项二：访客 05（你）**

玩家以为是选「谁杀了王执事」——实际选的是**下一个要被写进名册的人**。

## 十二、终局与反转（一句话收束）
