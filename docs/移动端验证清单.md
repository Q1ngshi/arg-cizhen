## 一、代码层已完成适配（v5，2026-08-14）

| 项目 | 改动 |
|---|---|
| 建筑图放大查看 | 鼠标事件 → **Pointer 事件统一**（鼠标/触屏均可拖拽平移）；新增**双指捏合缩放**（以双指中点为锚）、**双击/双触缩放**；`touch-action:none` 防浏览器手势抢占 |
| 建筑图批注擦除 | 擦除用 Pointer 事件 + 包围盒命中，触屏可用（点按/划过均擦） |

| 手机布局 | 既有 `@media (max-width:700px)` 保留；建筑图工具条允许换行（flex-wrap） |

## 二、真机手测清单（运营者执行）

> 建议准备两台手机（Android 微信 + iPhone），各走一遍；全程约 10 分钟。

### 环境准备
- [ ] 电脑运行 `run.bat`（或已部署的线上链接），手机与电脑同一 WiFi
- [ ] 手机浏览器输入 `http://<电脑局域网IP>:8081/desktop.html`（或线上链接）

### A. 微信内置浏览器（Android / iOS）
- [ ] 开机画面正常逐行出现；点击跳过正常
- [ ] 开场「叮咚」提示音**需要有一次点击后才响**（iOS 无点击不播 = 正常，不是 bug）
- [ ] 内网浏览器打开官网：官网可滚动、可点密码门；**进度（localStorage）在杀掉微信进程后仍保留**
- [ ] 双指放大建筑图纸：两指张开图纸放大、合拢缩小、单指拖拽平移
- [ ] 擦除模式：点击「擦除」→ 划过红色批注可擦掉；全部擦完出现还原轮廓
- [ ] 窗口最大化（▢）后关闭窗口再打开，布局不破
- [ ] 交接班生成 → 复制记录（iOS 微信复制弹窗正常；Android 剪贴板正常）

### B. iOS Safari
- [ ] 页面无横向滚动条（desktop 端）；窗口全宽显示
- [ ] 文件恢复进度条动画正常；恢复出的红本抄本可滚动到判断框
- [ ] 双指捏合缩放图纸不触发页面缩放（`touch-action:none` 生效）
- [ ] localStorage 持久化：关掉 Safari 标签重开，进度仍在（iOS 无痕模式 localStorage 会清空 = 正常，提醒玩家勿用无痕）

### C. 已知平台差异（正常现象，勿当 bug）
- 微信内置浏览器 Web Audio 首次播放需用户手势（点击/触摸）——开场音、钟声、破译音都在首次点击后可用
- iOS 低电量模式可能限制后台定时器——实时追逐「离线不扣」宽容制不受影响
- 手机端字体回退：手写体使用 KaiTi/STKaiti（Windows 有、手机可能没有，会回退 serif——不影响阅读与解谜）
