# 失踪案引子线 · 设计草案

> 2026-08-15 拟定（总经理拍板：A 方案新入口 + 孩子是「登记」新候选，8-27 大典前名册添名）。
> 目标：给游戏加一个**更有传播力的正门**——孩子失踪新闻 + 一卷建筑图，玩家从日常恐惧切入，
> 顺藤摸瓜汇入现有慈恩镇解密链，最终在名册线闭环：**玩家一开始为「查孩子」而来，
> 最后发现自己参与的是「决定下个孩子会不会消失」的系统**。
> 本文为设计确认稿，未动代码。

---

## 一、概念与定位

| 项 | 设计 |
|---|---|
| 形态 | 独立钩子页（新文件 `missing.html`）——「本地新闻 + 旧图纸扫描件」的静态页 |
| 入口 | 传播主入口之一：运营者/朋友分享 `missing.html`（而不是直接甩官网） |
| 玩家身份 | 低卷入旁观者：不是警察，是"偶然刷到新闻、翻到图纸"的好事者（银河电灯方法论） |
| 汇入 | 图纸备案单位「慈恩镇档案管理办公室」→ 链接进现有官网/终端 → 正常游戏开始 |
| 与世界观咬合 | 孩子 = 名册的新候选；绿苑小区 1 号楼 = 教会同一批人画的空间诡计；8-14 失踪 → 8-27 大典 |

## 二、剧情草案

### 新闻（missing.html 主体，本地新闻网风格）

> **《慈恩镇一男孩上学途中失踪，监控显示其未离开所住单元楼》**
>
> 8 月 14 日早 7 时 40 分许，慈恩镇绿苑小区 1 号楼一名 11 岁男孩（化名「小果」）离家上学后未到校，家人与校方先后报警。
> 警方调取小区及楼道监控：7 时 42 分，小果进入 1 号楼 3 层电梯，此后该电梯与楼道监控**未再记录到其身影**；
> 物业配合对整栋楼开展排查，未发现其离开或滞留迹象。目前公安机关正在进一步调查中。
> （新闻稿 ｜ 2026-08-15）

- 新闻页底部小字虚构声明（与官网一致，合规）
- 附件一栏：「热心市民提供的绿苑小区 1 号楼竣工图纸（扫描件，2 张）」——玩家点开图纸

### 图纸（两张 SVG，双图对照——学建筑图系统 v2）

**图 A：竣工备案图**（正式图框，SimSun 墨线）
- 1 号楼 3 层平面：302 室带一间「**储物间**」——**四面墙，没有门**（与教会「西侧储物间」同一诡计）
- 地下室标注「战时防空地下室（2009 年改建为地下车库）」
- 图框落款：「慈恩镇建筑队 · 竣工备案 2008.12 · 图纸存根：**慈恩镇档案管理办公室**」← 汇入入口
- 备案编号小字：`CE-2009-007`（与教会图纸 CE-2009-001 同系，暗示同一档案体系）

**图 B：建筑队内稿**（铅笔灰线 + 红笔批注，KaiTi 手写）
- 同一位置储物间：**有虚线门，通向墙后** + 红笔批注「预留通道，勿标注」
- 地下室角落：铅笔字「旧通道，已封。钥匙在（涂掉）」
- 角落一行小字（红笔）：「老板说，这间和槐树街那间一样，照旧样做。」← 勾连教会储物间
- 批注（更晚的笔迹）：「3 层电梯有 3 分钟盲区。够不够走到图纸外面去？」

### 孩子与名册的连接（终局闭环）

- 新闻日期 8-14 → 大典 8-27（中元节）——**失踪在大典前两周，正是"登记"的时点**
- 玩家通关最终卷后回看新闻：名册 8-27 前要添新名字；**二选一的落笔，写下的就是下一个名字**
- 好结局「记录未更新。没有新的名字。」= 小果没有被写上去——**开头的问题在结尾有了答案**
- 官网检索「小果 / 绿苑 / 失踪儿童」：系统冷静回应（「该名称无记录」或「同类记录：2009-03-17 1 件」——暗指林远案，让玩家意识到"这类事不是第一次"）

## 三、玩家流程

```
打开 missing.html（分享链接）
  → 读新闻：孩子失踪，监控说没出过楼 ← 日常裂痕
  → 看图纸附件：储物间没有门 / 内稿有虚线门 ← 空间诡计（海葵式）
  → 图纸角落：备案单位「慈恩镇档案管理办公室」→ 点击
  → 汇入官网（现有伪装层）——官网此刻是「查这楼图纸的地方」
  → 官网检索「绿苑 / 1号楼 / CE-2009-007」→ 系统回应（暗示与教会档案关联）
  → 沿现有解密链（linyuan → 管理员 → 07 → 建筑图 → 最终卷）
  → 终局：名册要添新名字；二选一 = 写下/不写下 → 回看新闻，闭环
```

## 四、基调三问 + 六红线

- **削弱伪装？** 否。本地新闻网 + 图纸扫描件是现实存在的载体；新闻腔/图纸版式按真实规范做
- **直白说破？** 否。图纸只有「没有门的房间」和一句「和槐树街那间一样」，不解释；孩子下落全程不揭
- **破坏打工循环？** 否。钩子页无任务（好事者视角）；汇入官网后恢复档案员循环
- **六红线**：新闻保持公文式冷静（不煽情、不卖惨、不渲染孩子画面）；不血腥（全文无伤害描写）；不出戏；不嘲讽。⚠️ 敏感度：孩子失踪是现实敏感题材，必须 100% 虚构（虚构镇/楼/化名/日期）+ 虚构声明，且全文不出现任何"尸体/伤害/阴谋直述"——恐怖全部来自监控矛盾与图纸留白
- **合规**：missing.html 底部虚构声明同官网；不与真实案件/真实地名关联

## 六、待你确认的点

1. **汇入路径**：图纸备案单位链接直接跳官网根（`index.html`），还是跳桌面终端（`desktop.html`）？——建议**官网根**（自然：查图纸 → 档案馆官网 → 玩家自己发现「加入我们」裂缝进终端）
2. **孩子名字**：「小果」化名可以吗？还是干脆不给名字（更留白，像小禾那样名字不出现）？
3. **图纸编号**：用 `CE-2009-007`（与教会同系）还是避开编号（避免提前暴露 CE 体系）？建议**用**——老玩家会心一笑，新玩家自然好奇
