## 使用建议

1. **工具**：即梦AI / 文心一格 / 豆包 / Midjourney 均可，中文提示词对国内工具更友好
2. **尺寸**：生成方形图（1:1），900×900以上，之后裁成圆形头像
3. **统一感**：5张尽量同一批生成、同一风格词，保持"同一档案卷宗"的质感
4. **死者与生者区分**：生成后用 CSS 处理（已内置：死者灰度+红叉），不需要在图片里加效果

## 替换方法

生成图片后放入 `img/` 目录，在 `index.html` 的 `characters` 数据中给每人加 `image: 'img/xxx.png'`，
然后把渲染逻辑里 `.char-avatar` 的 `文字首字` 改为 `<img>` 显示——这部分交给我处理即可，您只要把图片文件给我。
