# 建筑图系统设计文档

> 2026-08-11 定稿。风格参考：雨穴《怪屋谜案》——平面图本身就是恐怖载体，让玩家自己从图中发现"不该存在的空间"。

---

## 一、设计目标

把"字缝恐怖"从文字升级为**可视证据**：

- 玩家不再只是"读到"档案里的矛盾，而是**放大两张图纸，亲眼看到**矛盾
- 图纸不是装饰，是解谜对象：放大查看本身就是探索行为
- 与任务链无关的收藏型玩法（收录 → 查看），不卡主线，纯彩蛋深挖

## 二、玩法闭环

```
官网搜「图纸」──→ 2 件图纸档案
                    ├─ CE-2009-001 教会建筑图纸备案（加密，官网不可下载）
                    └─ 2009-补-002 手绘平面图 [下载附件] ──→ 收录
                                                              │
内部档案 CE-2009-001 ──→ 门禁密码 1942 ──→ 收录 ─────────────┤
                                                              ▼
                                  工具「建筑图」tab：卡片列表
                                              │
                              点击 → 全屏放大（25%-400% 缩放 / 拖拽 / 滚轮）
```

- 收录状态 = `localStorage cz_evt_blueprint_p2 / cz_evt_blueprint_001`（时间戳）
- 收录即触发桌面系统消息（"已收录建筑图纸：…存放路径 d:\archive\maps\"）
- 官网搜索「图纸」本身也有一条监视消息（"相关条目 2 件：1 件加密，1 件可下载"）

## 三、核心诡计：双图对照

| | 图 B：正式备案图纸 CE-2009-001 | 图 A：手绘批注图 2009-补-002 |
|---|---|---|
| 年代 | 1952 年测绘（2008.12 复核） | 2009 年 2 月批注 |
| 主殿西侧 | **一间「西侧储物间」——四面墙，没有门** | **一间被划掉的房间轮廓，只剩铅笔「？」** |
| 暗门（圣器室北墙） | 无 | 有（红笔虚线 + 箭头，"可容一人"） |
| 夹层（圣器室东墙） | 无 | 有（红笔，"备案图纸上没有"） |
| 地下室 | 标注"战时避难所" | 标注"深约 4.5 米" + 批注"灯从来不关" |
| 旋转楼梯 | 规整圆形楼梯间 | 虚线圆 + "旋转楼梯 17级" |

**玩家自己会得出的三层结论**：

1. 1952 年的图纸上有一间**没有入口的房间**
2. 2009 年有人想画它，画了又**划掉**，只留一个「？」
3. 画图的人知道它存在，但选择不画——**而手绘图上其他的"不该有"的东西（暗门、夹层）都画了**

→ 为什么暗门夹层敢画，这间房不敢画？留白，不解释。

## 四、基调三问检查

1. **削弱伪装吗？** 不。政府网站"附件下载"是标配；馆内工具看图纸是档案员本职；系统消息是监视语气不是游戏语气。
2. **直白说破了吗？** 不。没有一行文字解释"储物间有问题"，全部由玩家对照得出。
3. **破坏打工/被监视循环吗？** 不。收录 = 工作行为（下载附件、门禁解锁收录、消息确认存放路径），强化打工感。

## 五、红线检查

- 不跳吓 / 不血腥 / 不卖惨：无。恐怖全部来自图纸本身的信息差
- 不嘲讽玩家：门禁错误提示 = "请核对王执事生平信息后重试"（系统语气）
- 不出戏：图纸用 SVG 手绘感（KaiTi/铅笔灰线/红笔批注）与正式图纸（SimSun/墨线/图框标题栏）区分

## 六、留白钩子（下章素材）

- 那间没有门的「西侧储物间」——它通向哪里？（候选：与地下室夹层相连）
- 手绘图上被划掉的房间 = 正式图上的储物间，同一位置——为什么 2009 年画图人划掉它
- "复核：2008.12" = 王执事去世前最后一次复核（与对话录音同月）——他复核时看到了什么
- 1972 年失踪者（陈守正线伏笔）可能与此房间相关——待连

## 七、扩展方向

- 放大视图热区：点击房间出系统标注（雨穴式"资料 + 图纸"的交互化）
- 图纸可叠加对照（半透明切换：正式图 vs 手绘图逐区域比对）
- 手绘图可"擦除批注"还原原图（彩蛋：擦掉批注后房间轮廓自己浮出来）

## 八、实现要点（防回归）

- 两图均为纯 SVG 常量 `BP_A / BP_B`（desktop.html），无图片文件
- 放大查看：`transform: translate + scale`，以视口中心为锚缩放（`bpZoomBy`），mousedown/mousemove 拖拽，wheel 缩放（passive:false）
- 缩略图 = 完整 SVG 直接缩小（CSS 控制宽高），保证卡片与放大图一致
- 收录入口与门禁复用 1942（王执事密码链），不新造密码

## 九、v2 升级：数字诡计 + 挖掘揭示 + 叠加对照（2026-08-12）验收反馈「图有点直白」→ 升级为玩家自己「算」与「挖」出真相。

### 9.1 数字诡计（图上不写结论，数字自相矛盾）

| 图 | 数字 | 玩家推演 |
|---|---|---|
| 1952 正式图 | 地下室「层高 3.2m · 1942年建造」 | 3.2m ≠ 4.5m → 地下室**变深了 1.3m**，有人挖过 |
| 1952 正式图 | 旋转楼梯「直径2.1m」（烟雾数字） | — |
| 2009 手绘图 | 「旋转楼梯 17级」× 每级约 0.2m ≈ 3.4m | 3.4m < 4.5m → 楼梯**到不了底**，底下还有约 1.1m |
| 2009 手绘图 | 「地下室（深约 4.5 米）」 | 结论：夹层被两道算术题**证实存在** |

- 删除了直白行「1965年改作教会档案存放」（地下室用途一个字不提）
- 1942 建造年份与 dossier3 建筑结构表、门禁密码链互相印证

### 9.2 挖掘揭示（点击疑点 → 凿挖三次 → 露出物证）

- 疑点：正式图「西侧储物间」（唯一无门房间）。hover 时墙面浮出细裂纹提示
- 点击三次：每次裂纹增多 + 凿挖音效（Web Audio 合成：低频敲击 + 碎石噪声，无文件）+ 画面震动
- 第三次：墙体裂开（淡出）→ 露出墙内夹壁 + **1972 年寻人启事剪报**（报头残缺，与红本抄本「报头已经不完整了」同一张）
- 完成后系统消息「墙体检验完成。夹壁中发现纸张类物证，已登记入档。」+ 收录状态 `cz_evt_bp_dig`
- 手绘图上的同一位置**不可挖**（被划掉 = 无实体，小诡计）
- 雨穴式：剪报只写「1972年6月 离家未归 / 男 · 约五十岁 / 知情者请与槐树街7号联系」——是谁、谁贴的、谁撕的报头，全留白

### 9.3 叠加对照

- 放大视图工具条新增「对照」按钮（两图均收录后可见）
- 点击后另一张图以 50% 透明度叠在当前图上（viewBox 一致天然对齐），滑块调 20%-80%
- 缩放/平移与主图同步（同一 transform）
- 玩家自己拖动对比：同一位置，一间「无门储物间」vs 一个「被划掉的房间」

### 9.4 基调三问（v2 自检）

1. 削弱伪装？否。制图标注、检验记录、施工音效都是工作行为
2. 直白说破？否。数字矛盾与剪报内容无一行解释，全由玩家推出
3. 破坏打工循环？否。挖掘 = 档案员检验墙体 = 本职动作，系统照常登记入档

### 9.5 防回归（v2）

- SVG 元素设 class 必须用 `setAttribute('class', …)`（`className` 在 SVG 上是 SVGAnimatedString，赋值无效）——踩过
- `openBPZoom` 必须先 `classList.add('show')` 再量 stage 尺寸（display:none 时 rect 全 0，居中偏移算出 0）——踩过
- 缩略图卡片含完整 BP_B（含 onclick），digSpot 内必须 `if (!bpIsOpen) return` 防误触
- 两 SVG 根元素带 `id="BP-A"/"BP-B"` 供叠加对照判断当前图

## 十、v3 升级：批注擦除彩蛋 + 房间热区标注 + 触屏手势（2026-08-14 落地）

### 10.1 批注擦除彩蛋（手绘图 BP-A）

- 工具条新增「擦除」按钮（仅手绘图可见）：进入擦除模式后，**划过红色批注即可擦除**（Pointer 事件 + 包围盒命中，鼠标/触屏通用）
- 全部 8 处红批注（暗门线/箭头/标签、夹层矩形/标签、主殿三行批注）擦除完毕 → 被划掉的房间**还原出实线轮廓**（先画后划的物证）+ 系统标注「西侧房间 · 原稿实线闭合，后划除。用途：无记录。」
- 系统消息 + 埋点 `bp_erase` + 状态键 `cz_evt_bp_erase`（重开图纸保持还原态，擦除按钮隐藏）
- 与挖掘揭示互补：正式图（BP-B）储物间「可挖」，手绘图（BP-A）同位置「可擦」——两条路径都指向同一间房

### 10.2 房间热区标注（两图）

- 点击主殿/圣器室/地下室/旋转楼梯/西侧区域 → 顶部弹出系统标注（档案口吻，半句信息，不点破）
- 互文设计：手绘图圣器室「北墙暗门」vs 备案图圣器室「北墙无开口」；地下室「深约 4.5 米」vs「层高 3.2m」——玩家点着点着就对上了
- 西侧储物间（BP-B）即挖掘点，不设热区（点按仍是挖掘）

### 10.3 触屏手势（移动端）

- 鼠标事件 → Pointer 事件统一：单指拖拽平移、**双指捏合缩放**（以双指中点为锚）、双击/双触缩放
- `touch-action:none` 防浏览器手势抢占；交互元素（挖掘点/热区/红批注）不触发双击缩放（防误触）

### 10.4 基调三问（v3 自检）

1. 削弱伪装？否。擦除 = 档案修复室清理批注层 = 本职；热区标注 = 系统注解
2. 直白说破？否。还原只陈述技术事实（实线→虚线→划除），为什么不画、画给谁看，全留白
3. 破坏打工循环？否。擦除完成照常「已登记入档」，强化被记录感
