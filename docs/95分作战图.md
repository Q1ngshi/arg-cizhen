## 二、逐维度 95 关键动作（R1–R3 内容轮）

### 1. TINAG 伪装 90 → 93–95
- **A. 「慈恩镇网群」伪外部层**：机构概况页加「全镇单位」导航（镇政府/公安局/档案办/水利站/文教办……），档案办之外的单位点击进入「建设中」伪页面（1998 年风格占位）——制造「这只是镇网站群里的一个」的真实错觉
- **B. 历史版本时间胶囊**：URL `?ver=2009` 显示 2009 版首页（黑白、内容不同、标题「维护中」），入口藏在源码注释/控制台提示——与时间错位引擎同构
- **C. 假 404 页**：serve.js 与部署平台 404 页统一为「慈恩镇档案管理办公室 · 查无此档」风格（站内路径已提示「档案不存在」，补齐平台层）

### 2. 谜题可推导 85 → 93–95
- **A. CE-2009-006 闭环（隐藏卷宗）**：12/12 全发现 → 生成「归档码」（12 位，每位来自一处发现的事件时间哈希）→ 检索框输入 → 解锁卷宗六「执行者档案」：3-17 行动命令链（不揭女道士身份/小禾名字，守留白红线），补全「第三个人」留白
- **B. 跨玩家交接码（最强新机制）**：交接班记录尾部生成「本班归档码」（基于本班 cz_stage_log 稳定哈希）→ 官网检索框输入**他人的交接码** → 显示该玩家「调查进度摘要」（已发现 X/12、最后操作）——单人游戏获得「接力查案」的 ARG 协作感，对标 I Love Bees / 无光之日
- **C. 新检索词/新密码 ×3**：「守则」（守则全文，含更多矛盾条款）、「03:01」（时间戳档案）、「执行者」（引导 006）

### 3. 恐怖氛围 85 → 90–95
- **A. 深渊区全页面异变（被登记后）**：官网首页日期全部错位、新闻标题部分被替换、hero 变暗、倒计时血字慢闪——「系统被入侵」的视觉峰值（对标 Local 58 台标被劫持）
- **B. 指令反噬高潮**：被登记后「查阅须知」补充条款从「请立即停止检索」变为可执行指令（如「请关闭此页面」→ 点击后全屏黑底白字 3 秒）——遵守即恐怖
- **C. 音频变化**：被登记后桌面新增极低频心跳/纸张翻页环境音（Web Audio 合成）

### 4. 玩家卷入 85 → 92–93
- **A. 姓名输入**：桌面「记事本」首行让玩家填「值班员签名」，之后系统消息用该名称呼（「［姓名］，今天的补录档案还没整理」）——被点名
- **B. 行为感知**：系统消息引用玩家行为统计（「你已检索 N 次」「你打开了 7 个页面」）——「它知道我在干什么」
- **C. 滚动回应**：被登记后滚动到页脚出现一次性「你还在。」（meta，对标 DDLC）

### 5. 结局完整度 90 → 95
- **A. 第四隐藏结局「见证者」**：12/12 全发现 + 反抗点 3 + 不签收 → 隐藏结局变体：系统承认「你是第一个看完所有记录的人」，名册留下玩家的「见证者」批注（黑屏白字 + 独特余韵）
- **B. 完成度奖励**：全发现者最终卷多一页「已全部核对」归档戳（可晒）

### 6. 掉队处理 85 → 92
- **A. 交接摘要 recap**：重开桌面时若已有交接班记录，开场消息变为「上一班交接摘要」（读取已生成记录前几行）——Phillips catch-up 落地
- **B. 档案柜回溯**：确保已读文档跨会话可回看（内部档案已覆盖；补「已读标记」）

### 7. 传播协作 80 → 90–93
- **A. 跨玩家交接码**（同 2-B，传播主引擎）
- **B. 唯一访客编号**：最终卷后显示「访客 05-XXXX」（行为哈希），玩家晒「我是 05-8F3A」
- **C. 社区挂靠（运营）**：谜页集建档、迷雾 Wiki 建 ARG 档案、B 站实况投稿引导文案

### 8. 藏宝深度 82 → 90–93
- **A. PNG 隐写**：程序生成一张带 tEXt chunk 的 PNG 证据图（如「名册首页扫描件」），下载后右键属性/文本打开可见藏字（node 可生成，零素材）
- **B. 剪贴板篡改**：复制交接记录时剪贴板末尾被追加一行（「归档码：……」）——系统偷改玩家复制的内容
- **C. 文件属性撒谎**：桌面「文件恢复」列表显示文件修改时间（如「2009-03-17 03:01」vs「2026-08-14」并存）

## 四、95 的「最后一分」在哪（诚实说明）

1. **传播维度的实证分**（+1~2）：机制做到 90，93–95 需要真实玩家数据（谁发现了 12/12、交接码有没有被互相输入）——这只能靠上线后回收
2. **藏宝的「惊叹分」**（+1）：PNG 隐写/剪贴板做得再好，也需要玩家实际「哇」出来——依赖实况/解析视频传播
3. **伪装的「误入分」**（+1）：网群/历史胶囊的拟真度，最终由「有没有玩家真以为这是政府网站」判定

**结论**：开发侧全力可到 **93–94**；95 = 开发 94 + 运营实证 1–2。若目标必须在 95，R4 的运营动作不是可选项而是必选项。
