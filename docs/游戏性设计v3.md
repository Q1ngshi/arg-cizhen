# 《慈恩镇 · 赎罪祭》游戏性设计 v3

> ⚠️ **已归档（2026-08-14）**：本方向被 v4 终局设计（[河神-终局剧情-设计.md](河神-终局剧情-设计.md)）取代。
> 石室双结局 / 安息祭设定与 v4 的 名册·恩慈大典·河神 世界观冲突，不再实施。
> 保留本文件作设计溯源；「三疑目标」方向感由桌面任务链（三任务闭环）承接。

> 目标：把"可点击的有声书"升级为"推理爽 + 自责后劲"的互动叙事游戏
> 核心循环：收集线索 → 形成假设 → 主动验证 → 得到反馈（对了推进 / 错了迷雾）

## 二、阶段0：档案馆开场（钩子）

**身份**：返乡人——"你回到了慈恩镇"，帮忙在亲戚的小郑档案馆归档。

**交互**（零门槛、有发现感）：
1. 第一屏：档案馆工作台。"今日任务：将五份档案归入卷宗柜。"
2. 玩家逐份点击归档（点5下，快速完成，建立"我在做事"的参与感）
3. 系统核对："登记册：5份。柜中：5份。核对无误。"（让玩家放松）
4. 角落还有一份散落的文件夹 → "等等……登记册上，没有这份。"
5. 翻开：泛黄照片 + 批注"失踪。未归档。"
6. 钩子句："镇上没有人提起过他。但你总觉得，这个名字在哪里听过。"
7. 任务目标出现（三疑），进入侦探板

## 三、阶段1-2：三疑目标 + 侦探板（验证式改造）

### 三疑目标（顶栏任务条）
- ① 谁选中了他？
- ② 怎么带走的？
- ③ 埋在了哪里？
- 每完成一个 → 目标打勾 + 仪式感反馈（"这条线，对上了。"）

### 侦探板改造（从"点击读文本"到"判断+验证"）
保留现有人物卡/连线/档案结构，改造三处交互：

| 现状 | 改造后 | 游戏性提升 |
|---|---|---|
| 点击人物 → 直接看档案 | 人物档案分两层：**公开层**（身份/职业）与**深挖层**（遗物/关系）。深挖层需要玩家"提出正确问题"解锁 | 玩家要思考"该查什么" |
| 点击连线 → 直接看关系文本 | **连线=仪式链条验证**：玩家看到人物对后，先**判断**"他们之间是什么关系"（3选1：合作/敌对/无关），选对→揭示真实关系文本；选错→"记录矛盾，待查" | 想出来才看得到 |
| 死者红X直接显示 | 死者卡片先"无状态"，玩家通过档案推断"这个人已经不在了"后，红X才标记上 | 自己发现"谁死了" |

### 反馈设计
- 判断正确：关系文本揭示 + 金线点亮 + 轻微震动
- 判断错误：系统显示"记录矛盾，待查" + 线索回到档案（不惩罚，只拖延——叙事游戏不卡玩家）

## 四、阶段3：怪屋探索（找茬定位式）

**核心改造：图纸上的房间标注与档案对不上，玩家负责"定位"**

1. 图纸初始显示：6个房间**无名称**，只画轮廓 + 档案引用编号（如"3号房""5号房"）
2. 玩家在档案/证词中读到房间线索（如孙义海档案提到"锅炉房"、赵秀兰日记提到"阁楼"——注：锅炉房在本图纸，阁楼不在——**玩家需要判断哪些房间与本案有关**）
3. 验证动作：玩家在图纸上**选择"本案相关的房间"**（点选），选对→房间出现名称+可探索；选错→"这间房……积满灰尘，似乎很久没人来过"（不惩罚）
4. 罪证机制保留：相关房间内埋3份遗物（发现时震动）
5. 隐藏空间（安息祭石室）浮现条件保留：3罪证集齐

**找茬谜题设计**（示例，内容可替换）：
- 档案提到"旧锅炉房"——图纸上标着"杂物间"？玩家需要指出"这个房间被改名了"（长按/点选后选择"重命名"？简化：点选后系统问"你确定这是锅炉房吗？"，玩家确认）
- 简化方案（推荐）：图纸6个房间，其中**3个是本案相关的**（忏悔室/档案室/锅炉房），3个无关（主厅/储藏室/走廊）——玩家通过档案判断选3个，选对全部→开启罪证收集；这本身就是"推理+验证"

## 五、阶段4：旧档案判断式

现有7份文件改造为"阅读+判断"：
- 3条村民证词：读完后出现判断题："这位说话的人，在回避什么？"（3选1，答对→证词标记"已破译"，答错→可重选）
- 教堂修缮记录/失踪登记/报纸：保留直接阅读（信息碎片）
- 捐赠记录（特殊）：**触发"你看到了自己的名字"**（保留震动+标记）

## 六、阶段5-6：仪式倒计时 + 石室双结局

### 倒计时氛围（不硬卡玩家）
- 指控解锁后，顶部出现"距离安息祭：今晚"倒计时条（视觉流动的暗红细线，无硬性超时）
- 档案箱/怪屋探索时偶尔闪出提示："教堂的门，已经关了。"

### 石室之门（真选择·双结局）
指控后进入石室门前场景（黑屏+一句描述）：
> "你站在石室门前。铁门上的锁，已经被人打开了。"
> "你听见里面……有呼吸声。"
> 两个按钮：【推开它】【离开这里】

| 选择 | 结局差异 |
|---|---|
| **推开它** | 第一层反转完整（共谋者）+ 第二层执行者收尾："你终于，走了进去。"（直面） |
| **离开这里** | 第一层反转被压缩（"你又一次，走开了"）+ 第二层执行者收尾："和十七年前一样。"（逃避） |

**双结局让"指控"这一步有了真正的后果**，且两个结局都指向第二层反转（执行者），保持叙事主线完整。

## 七、阶段7：双层反转黑屏（保留v2）

- 看到名字 → 完整第一层（共谋者）
- 没看到名字 → 替代文本（"档案会撒谎。你也在撒谎。"）
- 第二层：执行者（"七年已满……不是作为祭品，是作为执行者"）
- 重玩彩蛋保留
