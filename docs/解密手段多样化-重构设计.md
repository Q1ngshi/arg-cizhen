## 六、兼容性与基调

- 全部 localStorage / sessionStorage 键不变，老玩家进度不受影响
- 破译反馈 = 系统消息口吻（监视感强化，不破坏伪装）
- 值班员引导直白但不出戏；无跳吓 / 血腥 / 嘲讽 / 卖惨 ✓
- 卡壳风险：所有新线索有 ≥1 条明示引导，双保险存在

## 七、验收标准

1. 新玩家按自然流程：官网四门全部可解，其中 1942 必须经过计算器验算才能安心输入（直接输也对，但系统有反馈）
2. 埋点全流程测试 15+ 项断言全过（含 calc_break、bp_plate）
3. 07 卡点路径（搜索 1942 保险丝）仍可用
